# Контекст: анализ длинных выписок

Обновлено: 2026-09-20

## Последние изменения

- Строгий разбор выписки, AI-категоризация чистых данных и адаптивная таблица внесены в ветке `feat/statement-template` (коммит `b3871d7`).
- Светлая/тёмная тема и интерактивная диаграмма пришли из `origin/main` при слиянии PR #4 `modern-design` (merge-коммит `550d2d3`); при разрешении конфликта сохранены обе группы изменений.

## Проблема

Один запрос к модели с полугодовой выпиской мог вернуть только часть операций. Сервер агрегировал полученный неполный массив без сверки с исходным документом, поэтому дашборд показывал период примерно в 1,5 месяца вместо всех шести.

## Актуальная архитектура

- `pdf-parse` извлекает из цифрового PDF сухой текст только в памяти запроса.
- Профиль `bankStatementTemplate` проверяет формат Kaspi Gold и детерминированно разбирает каждую строку операции: дату, сумму, тип и детали. ИИ не видит исходный PDF и не извлекает из него операции.
- Сервер сам формирует период, число операций, суммы и категории в диаграмме. Переводы получают категорию `Переводы`, доходы — `Другое`.
- OpenAI получает только уже разобранные расходы небольшими пакетами и возвращает соответствие «идентификатор операции → категория». Ответ отклоняется, если в нём отсутствует или повторяется хотя бы одна категория.
- Инсайты запрашиваются отдельным коротким вызовом только по итоговому чистому списку операций.
- Добавлен unit-тест детерминированного разбора строк Kaspi Gold.

## Совместимость с Kaspi Gold и кэшем

До разбора текст всегда проходит строгую проверку `bankStatementTemplate`: подпись Kaspi Bank, заголовок Kaspi Gold, таблица и формат строки операции. Кэш вызывается после этой проверки и хранит только успешный итоговый анализ; он не может превратить неподходящий документ в cache hit.

Кэш результата действует до 7 дней в памяти процесса. После выкладки процесс нужно перезапустить, чтобы не использовать результаты, построенные прежней логикой.

## Проверка после выкладки

1. Загрузить обезличенную полугодовую выписку Kaspi Gold.
2. Убедиться, что в таблице есть операции с начала и конца периода.
3. Сверить число операций и сумму расходов с выпиской или банковским приложением.
4. Повторно загрузить тот же файл: результат должен совпасть, а ответ сервера иметь заголовок `X-Analysis-Cache: HIT`.

## Ограничения

Парсер рассчитан на известный экспортный формат Kaspi Gold. При изменении банком текста заголовка или структуры строки операции нужно обновить регулярные выражения в `bank-template.ts` и добавить реальный обезличенный пример в тесты. Сканированные PDF без текстового слоя по-прежнему не поддерживаются.
