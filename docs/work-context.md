# Контекст проделанной работы

Обновлено: 2026-09-20

## Выполнено

- Подготовлен MVP «Карманный бухгалтер»: React/Vite-клиент, Express API и анализ текстовых PDF-выписок через OpenAI Responses API.
- Добавлен профиль единственного поддерживаемого формата — **Kaspi Gold**. Перед отправкой текста модели сервис проверяет:
  - подпись АО Kaspi Bank;
  - заголовок выписки Kaspi Gold с произвольным периодом;
  - заголовок таблицы операций;
  - формат хотя бы одной строки операции.
- Некорректные документы — другой банк, справка об остатке, скан без текста или неполная выписка — получают понятную ошибку в интерфейсе и не отправляются в OpenAI.
- Добавлены unit-тесты профиля Kaspi Gold: успешная проверка, отклонение другого банка и справки без таблицы операций.
- Добавлен серверный кэш успешных анализов: он получает только уже проверенную шаблоном Kaspi Gold выписку, хранит результат в памяти процесса до 7 дней и не сохраняет PDF или текст на диск.
- В основную разработческую ветку добавлены shadcn/ui и Tailwind CSS v4; в проекте доступны базовые UI-компоненты `alert`, `badge`, `button`, `card` и `table`.

## Ключевые файлы

- `src/server/bank-template.ts` — проверки формата Kaspi Gold.
- `src/server/analyzer.ts` — вызов OpenAI, Structured Outputs и Zod-валидация результата.
- `src/server/analysis-cache.ts` — ограниченный кэш успешных результатов и защита от параллельного повторного анализа одной выписки.
- `src/server/summary.ts` — серверный расчёт итогов по операциям.
- `tests/bank-template.test.ts` — тесты проверки банковского шаблона.
- `docs/development-context.md` — общий контекст MVP, API и следующие шаги.
- `docs/ui-development.md` — правила работы с shadcn/ui.

## Что осталось

1. Прогнать обезличенную настоящую PDF-выписку Kaspi Gold с настроенным `OPENAI_API_KEY`.
2. При расхождении реального формата с шаблоном скорректировать регулярные выражения в `bank-template.ts` и расширить тесты.
3. Добавить обезличенный demo-PDF в `assets/` и обновить README.
4. Проверить контейнерный запуск через Docker Desktop.

## Важные ограничения

Не коммитить `.env`, API-ключи, реальные выписки и любые персональные финансовые данные. Выписки обрабатываются в памяти одного запроса и не сохраняются приложением.
